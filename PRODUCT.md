# Compass

## Platform

web

## Users and purpose

Employees record concrete observations about colleagues. HR configures and reviews a 12-week developmental AI evaluation pilot. Employees do not assign scores. Fireworks assesses a fixed rubric; HR reviews evidence before publication.

## Constraints

The existing evaluation system remains authoritative. The pilot uses explicitly enrolled users, frozen cycle settings, traceable evidence, confidential source feedback, and reviewed employee themes. Preserve Compass's existing interface and navigation conventions. No production activation or external reminders in this implementation.
